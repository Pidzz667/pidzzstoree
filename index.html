Proses pengaitan UID manual dilakukan oleh admin melalui WhatsApp. Jika kamu sudah melakukan transfer tetapi admin belum membalas, berarti admin sedang offline. Harap tunggu sampai admin kembali online dan membalas pesanmu.

✦ PANDUAN PIDZ STORE

Cara Pembelian / Proses

  1. Masuk ke website resmi PIDZ STORE.
  2. Pilih ID yang kalian suka sesuai selera dan budget.
  3. Klik Beli Sekarang.
  4. Jika muncul QRIS, scan melalui aplikasi pembayaran seperti DANA, GoPay, OVO, dan lainnya.
  5. Jika sudah melakukan pembayaran sesuai nominal yang dipilih, klik SUDAH BAYAR – KONFIRMASI VIA WHATSAPP.
  6. Kirim bukti transfer kepada admin.
  7. Tunggu admin melakukan konfirmasi.
  8. Buat akun Google/Facebook/X baru yang belum pernah terkait dengan Free Fire.
  9. Kirim informasi akun yang diperlukan kepada admin, lalu tunggu admin memproses pengaitan UID.
  10. SELESAI.
Proses pengaitan UID manual dilakukan oleh admin melalui WhatsApp. Jika sudah transfer tetapi admin belum membalas, berarti admin sedang offline. Harap tunggu admin kembali online.
